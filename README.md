# Placement Prediction Using Logistic Regression

This project explores student placement prediction using a sample dataset.
It uses Python and machine learning to analyze student data and predict placement outcomes.
The notebook covers data exploration, preprocessing, model training, and evaluation.
It demonstrates a basic end-to-end classification workflow using Logistic Regression.
**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
